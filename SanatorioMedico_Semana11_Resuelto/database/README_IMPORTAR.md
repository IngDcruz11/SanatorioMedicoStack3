# Importar las colecciones en MongoDB Compass

Esta carpeta contiene las tres exportaciones JSON solicitadas en la Tarea Semana 11.

1. Iniciar MongoDB y abrir **MongoDB Compass**.
2. Conectarse a la instancia local y abrir/crear la base **sanatorio_medico**.
3. Crear las colecciones `sucursales`, `pacientes` y `medicos`.
4. En cada colección usar **Add Data > Import JSON or CSV**.
5. Importar el archivo correspondiente de esta carpeta.
6. Verificar que cada colección tenga al menos cinco documentos.

Los `_id` ya vienen como ObjectId en formato Extended JSON, por lo que pueden utilizarse inmediatamente en los endpoints GET/PUT/DELETE por id.
